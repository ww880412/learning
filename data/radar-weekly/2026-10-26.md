# Agent工作台雷达 · 周报（2026-10-19 ~ 10-26，北京时间）

**结论先说**
1. **身份权限 / MCP 网关这个空白方向，本周第一次有像样的开源样本。** 最完整的是 [Tuskira AI Agent Gateway](https://github.com/Tuskira/ai-agent-gateway)：每次工具调用都按 agent 档案强制授权，工具凭据由网关按请求注入，agent 拿不到。闭源方面，Vercel 公开了「计划即权限」的完整设计，可以抄。
2. **标准层定型。** Agent Skills 已捐给 Agentic AI Foundation，和 MCP 同一个基金会，官方称 70+ 平台已接入。Claude 开始支持 MCP 的长任务（Tasks）和向用户追问（Elicitations）。我们的插件格式可以放心以 SKILL.md + MCP 为底。
3. **供应链警报。** LiteLLM 1.107.0 在 PyPI 和 Docker 上被投毒，盗取 SSH、云凭据、AI 工具 token、MCP 配置和网关里存的各家模型 key。网关是凭据最集中的单点，我们的模型网关必须锁版本、校验哈希、隔离发布流水线。

*星数、创建日期、License 均为 2026-10-26 GitHub API 实测，日期按北京时间。标「自报」的数字都没有复现。*

## 三、最值得抄的 5 个作业
1. **[Tuskira AI Agent Gateway](https://github.com/Tuskira/ai-agent-gateway)**：直接对应 MCP 网关空白。
   - 每次 tools/call 都按 agent 档案校验，不只是在工具列表里过滤；key 绑定档案后，调用方不能自报身份。
   - 凭据从加密库按请求注入，可轮换。
   - Skills 挂在档案上，通过 MCP 下发。
   - 要读的文档：docs/profiles.md、docs/connectors-and-credentials.md、docs/security-model.md。
2. **Vercel「计划即权限」**（闭源，博客）：
   - 只读的调查自动执行；
   - agent 出一份计划，写明要做什么、需要哪些权限，用户一次批准；
   - 批准后签发只含这些权限的短时 token；
   - 恢复执行前重新检查计划是否仍有效；
   - 校验计划、批准、签 token 三处共用同一份权限注册表。
   - 这套比逐步点批准好，可以直接做成工作台的审批模型。
3. **[PandaCode](https://github.com/aicodeking/pandacode)**：
   - 多协议接入层（docs/providers.md）；
   - 云沙箱抽象（src-tauri/src/cloud/*.rs）；
   - Skills 目录和适配（src-tauri/src/skills/{catalog,adapter}.rs）；
   - 架构师 + worker 团队、每任务一个 worktree。
   - 等于一份现成的工作台模块清单。
4. **[Aletheia](https://github.com/firatmio/aletheia)**：记忆带代码锚点，召回时机械复核，失效的不进上下文。和库里已有的 dsh-memory-gate（#215，「检索到 ≠ 注入」）组合，就是企业记忆层可靠性的底线。
5. **[Reason Network](https://github.com/reason-machines/reason-network)**：多人多 agent 协作的最小协议，只有 3 个工具，加上「一台电脑只能代表它的主人」的身份证明（src/proof.rs）。

候补：
- devin-vuln-fixes：一份 Skill 配多家清单的分发方式。
- agent-eval：用统计检验做 CI 门禁。
- erebus：给每次执行签可验证回执。

## 四、空白方向有无进展
- **MCP 网关 / 工具鉴权：有，而且是本周最大进展。**
  - Tuskira：按档案强制授权，凭据由网关注入。
  - skgate：MCP 的 OAuth 2.1 实现（internal/mcp/oauth.go），外加 OIDC 管理员登录、虚拟 key。
  - heldkeys：启动 agent 前盘点它在本机、沙箱或 CI 里能拿到哪些凭据。
  - 闭源参考：Alter（YC 的商业 agent 特权访问管理）、Vercel 的计划即权限。
- **SSO/RBAC：有。** Antirion 内置 OIDC、SAML 登录、SCIM 账号同步和权限控制。Tuskira 有多租户隔离。
- **合规审计：有。**
  - erebus：每次执行签发可离线验证的签名回执，cosign 就能验；README 明确说它不证明模型算对了。
  - OpenShell 的审计日志改为 OCSF 标准格式。
- **计费：有。** Antirion 做多级预算和成本账本；Stigg SDK 给出「调用前查权益、调用后计量」的接口形态。开源的团队分摊（chargeback）方案仍然没有。
- **按权限过滤的检索（ACL-aware RAG）：仍然空白。** 基线还是 Onyx；OpenViking v0.5.2 的隐私提取最接近。
