X 简报 · 10/30（周五）

今日主线
  1. Codex 派子 Agent 默认整段继承父对话：Matt Pocock 发现 Codex 派出的子 Agent 多数是「fork」父会话、带着全部上下文启动，code-review、implement-spec 这类靠干净上下文的 skill 因此失效；他没改 harness，只给 8 个会派子 Agent 的 skill 各加一句「每个子 Agent 用全新上下文启动」（Matt Pocock 原帖、一笔 原帖、skills PR #1341、Codex issue #20077）
    前提或争议：原因可查：Codex 的 spawn_agent 不传 fork_turns 时默认 "all"（全历史 fork），OpenAI 自家 plugins 仓库的 superpowers 说明也写着要传 fork_turns: "none"；OpenAI 没就默认值改不改表态。Matt 10/12 还以「这是 harness 的事」关过同类 issue，这次改口在 skill 里补
    为什么值得看：工作台里凡是「并行审查 / 独立研究」的子 Agent，都别假设 harness 会自动隔离——在 skill 文本里写明「不带父对话」，调用 Codex 时显式传 fork_turns: "none"，再抽查 ~/.codex/sessions/ 里子会话有没有 forked_from_id
  2. OpenAI：Pro 各档和 Business Premium 用量翻倍，12 月起可能 ChatGPT 与 Codex 共用额度：Codex 负责人 Tibo 宣布 Pro 100/200/500 和 Business Premium 所有用量上限即日翻倍，原定的 Pro 200 降额取消、Codex 和 Work 用量不降；dot 的加长额度「暂时」继续、仍单独计算。同一天 Tibor Blaho 在 ChatGPT 网页结账页翻到隐藏文案「从 12 月起，套餐用量将在 ChatGPT 和 Codex 之间共用上限」（Tibo 原帖、宝玉 原帖、TestingCatalog 原帖、Tibor 原帖、原帖、Codex 用量说明）
    前提或争议：翻倍是 Tibo 本人官宣，Plus 不在名单；宝玉按旧倍数推算 Pro 100 从 5 倍到 10 倍、Pro 500 从 25 倍到 50 倍，每美元能用的量不变，价格没提。12 月共享上限只是隐藏文案，目前没看到 OpenAI 公告；帮助中心现写的是 Codex 与 Work 共用额度，普通聊天是否并入还没定
    为什么值得看：如果在 Pro 上重度跑 Codex，这个月额度宽裕；但 12 月可能和日常聊天抢同一池子，预算和多账号分工现在就该按「合并」做预案，别把翻倍当长期常态
  3. Spawn：一群 Fable Agent 每小时往生产发版，一小时没发算 SEV-0：Simon Willison 推荐 Jacob Sansbury 写 Spawn（多人游戏，玩家用提示词改世界）的开发方式：Agent 直接改线上代码、每小时上线；约 60% 工作从生产报错、游戏内 AI「Savi」自己提的 bug、日志异常开始；坏改动 30 秒内定点回滚；告警会唤醒负责该事故的 Agent；他们称每月 token 花费超 300 万美元、是工资的 30 倍（Simon Willison 原帖、原帖、Simon 博客）
    前提或争议：全部是创始人自述，没有第三方核实；Simon 认为这套放到出错代价高的软件上很难想象，游戏是低风险场景；作者说 Fable 5/5.1 才撑得住，Opus 5.5 不够，GPT-6 Astra 修安全问题时把功能全关了
    为什么值得看：能抄的是闭环而不是速度：产品内 AI 自动提 bug → Agent 判定修 / 不修 / 待决策 → 修完在原对话回给用户；外加「定点 30 秒回滚 + 告警直接唤醒 owner Agent + 故意制造故障演练恢复」
  4. Anthropic 公开「自我评估」：Claude 每轮回答后自己给对话打安全标记：Anthropic Safeguards 博客说，从 6 月 Fable 5 起，每轮回答后追加一句短指令，让 Claude 输出固定格式的安全评估（是否可疑、危害类别、是否拒绝、1–10 的复查优先级、一句理由），只做事后离线标记；靠 KV cache 复用，官方称整体推理算力增加不到 2%；以更贵的提示式分类器为基准、误报 1% 时抓到 78% 可疑对话、94% 的高优先级（Anthropic 原帖、TestingCatalog 原帖、宝玉 原帖、Safeguards 博客）
    前提或争议：数字都是 Anthropic 自测、且以自家分类器为准；零数据保留流量不跑；官方说单条标记不等于违规，部分领域按组织汇总多条高优先级才转人工；当场拦截效果弱（24 个网攻任务里攻击成功从 19 个降到 13 个，分类器能降到 6 个），专门针对它的攻击者可能绕过
    为什么值得看：对工作台是一个便宜的监控做法：主 Agent 每轮结束顺手吐一条结构化自评，进离线队列再升级到贵的审查。Anthropic 聚类出的新问题里就有「提示注入」和「Agent 执行了用户没授权的操作」，正好是工作台审计要盯的两类
  5. Claude API 单次请求上限 32 MB → 128 MB：Claude 开发者账号宣布 Messages 和 Token Counting 两个接口单次请求上限提到 128 MB；以前长时间 computer use（几十张截图）和大 PDF 常常上下文还没满就被 32 MB 卡住。宝玉补充：超过 20 张图的请求，单图长宽上限从 2000 放宽到 3000 像素（ClaudeDevs 原帖、宝玉 原帖、官方文档）
    前提或争议：官方文档已更新；只适用于 Anthropic 自家 API，Bedrock 仍 20 MB、Google 托管 30 MB、AWS / Foundry 等 32 MB；托管 Agent 用的 Sessions、Agents、Environments 接口仍是 32 MB；价格不变，超限返回 413
    为什么值得看：工作台里跑浏览器或桌面操作的 Agent，可以少做「截图压缩 / 提前切会话」的补丁；但走云厂商或托管 Agent 接口的链路别跟着改阈值，按最小的那个上限做保护
  6. LangChain Managed Deep Agents 0.10：异步子 Agent + 内置浏览器，登录时把窗口交给人：Harrison Chase 说 harness 的很多难题要靠 harness 和基础设施更紧地结合来解，0.10 加了异步子 Agent（长任务交出去，主 Agent 继续）和浏览器；团队成员 ndrezn 说网站要登录时 Agent 把浏览器窗口交给用户，密码不进模型（Harrison Chase 原帖、原帖、ndrezn 原帖）
    前提或争议：LangChain 官方产品发布，功能描述是厂商自述；没看到第三方实测
    为什么值得看：「登录交给人、凭据不进上下文」是工作台浏览器能力最该抄的一步；异步子 Agent 则对应上面 Codex fork 的问题——派出去的任务该带多少上下文，要做成显式参数
  7. Google 关停 Jules，能力并进 Antigravity：Jules 官方宣布收拢编码 Agent 产品线，11 月 11 日后只读、12 月 31 日关停；后台远程执行等能力要并进 Antigravity。同日 Antigravity 上线插件市场，接入 Jira、Confluence、Linear、Figma、Datadog、Vercel 等（Jules 原帖、TestingCatalog 原帖、原帖、Jules 关停公告）
    前提或争议：关停日期出自 Jules 官方 changelog；官方给了导出办法：装 Jules CLI 后把一段导出提示词交给 Claude Code 等本地 Agent，导出设置、环境变量、记忆和每个会话的计划、日志、补丁；导出里有环境变量明文，要放在仓库外
    为什么值得看：用 Jules 跑后台任务的，11/11 前导出；这份「让本地 Agent 执行导出」的做法也可以直接当工作台数据迁移的样板
  8. Mistral 开源 Mistral Large 4（Le Chonk）权重：Mistral 发布 1T 总参、52B 激活的多模态 MoE 权重，官方称开源模型里 FrontierCode 2.0 第一（19.7%）、Terminal-Bench 4.0 41%，AA Coding Agent Index 48% 与 GLM-5.3 持平但每任务少用 47% token；三档推理；API 每百万 token 输入 $0.70 / 输出 $2.10（TestingCatalog 原帖、Mistral 原帖、Gorden Sun 原帖、Mistral 公告）
    前提或争议：跑分是官方自报，技术报告「即将发布」；许可是改过的 MIT，做模型即服务（MaaS）商用要另签授权；Gorden Sun 认为整体还比不上 GLM 5.3 和 DeepSeek V4.1 Flash 1017
    为什么值得看：要私有部署、对数据主权敏感的企业客户多了一个可商用的大号开源选项；进路由前先在自家任务上和 GLM、DeepSeek 对比 token 用量
