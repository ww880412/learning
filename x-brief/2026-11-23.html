X 简报 · 11/24（周二）

今日主线
  1. Anthropic 推出 Claude Ship（公测）：把 GitHub 拉取请求的审查、修改和按团队策略审批串在一起；Code Review 已正式可用，PR Steward 与 Claude Approvals 为公开测试，面向 Team 和 Enterprise（官方文档，北京时间 11/24）：官方说明，Code Review 对照周围代码找逻辑错误、安全问题和边界情况，并把发现按严重程度写成行内评论；PR Steward 处理失败的检查、合并冲突，以及来自人和审查机器人的反馈，并推送修改提交，但设计上不批准、不合并；Claude Approvals 读取仓库里的策略文件（文档示例为 .claude/approvals.yml），报告还需要谁批准，也可在策略允许时发布批准。开发者可在 Claude Code 里对自家变更运行 /ship，命令正在命令行和桌面端滚动开通；管理员也可按仓库打开，不必每条都手动 /ship。Claude Code 负责人 Boris Cherny 称自己整天在用，并说所在团队在更广流程里加入这层审查后，6 月到 9 月合并的 PR 增加一倍以上，回退比例下降超过 40%——这是厂商自述（官方文档、ClaudeDevs、Boris Cherny、Addy Osmani）
    前提或争议：不向已开通零数据保留（ZDR）、采用 HIPAA 配置或使用客户托管加密密钥的组织提供。批准检查只有在你们把它设成 GitHub 必需检查时才会拦住合并；observe 模式通常不拦住，但观察模式也计费。官方警告：若使用 GitHub auto-merge 或合并队列，而策略又不要求真人批准，变更可能无人经手就合并。各 Agent 按 token 从组织的 usage credits 计费，与套餐包含用量分开；关掉 usage credits 不会自动停掉已开启的 Agent。文档写合资格的 Enterprise 可申请促销额度，具体金额和日期以官方条款为准
    为什么值得看：企业 coding agent 工作台如果要把「写完就等真人过 PR」改成可配置的自动审查和修复，可直接对照这三步：先开 Code Review，Steward 先用手动 @claude steward，Approvals 先观察再强制；分支保护仍决定能不能合，策略不要在 auto-merge 下写成无人审批
  2. Anthropic 官方称，连接器和技能合并为插件；Free、Pro、Max 和 Ultra 现已可用，Team 和 Enterprise 即将推出，并可浏览 10,000 多个插件（官方公告，11/24）：官方写道，现在用同一种方式给 Claude 接工具、教它新技能，或两件事一起做（原帖、插件目录）
    前提或争议：这是官方产品公告，目录规模和团队版上线时间以插件页为准；公告没有在帖子里写清企业管控、审核和数据范围
    为什么值得看：工作台如果同时维护 MCP 连接器和 skill，可以先看成同一套插件分发，再决定要不要跟 Claude 的目录对齐
  3. Anthropic 官方宣布，企业前沿防护（Enterprise Frontier Safeguards，EFS）的零数据保留方案进入公开测试，面向符合条件的企业客户（官方公告，11/24）：官方称，EFS 可在多次请求之间检测复杂滥用，同时与零数据保留兼容：Anthropic 和云厂商都不留存企业数据。自 9 月宣布以来，已与 100 多家客户继续打磨，其中包括约四分之一的财富 100 强，以及医疗、金融和律师等对数据可见性要求更严的行业。文章写，检测由 Anthropic 运行，日志可留在客户自己的环境，并由客户管理的密钥保护（官方文章、原帖）
    前提或争议：目前是公开测试，不是所有企业都能开通；官方文档同时写明，Claude Ship 不向已开通 ZDR、HIPAA 配置或客户托管加密密钥的组织提供，也就是自动过 PR 和零保留目前不能同时选
    为什么值得看：要做企业工作台，先确定数据能不能离开客户环境；若必须零保留，审批自动化要另找不依赖 Ship 的办法
  4. Antigravity 负责人 Varun Mohan 宣布一组更新：全体重置 Gemini 额度；付费 Pro 可用 Gemini 4 Carbon，Hydrogen 向所有用户开放；付费 Pro 原先单独的 Argon 额度并入总额度；编排器可分别指定模型和推理力度；长任务增加清单（厂商人员公告，11/24）：他写道，重置是因为各档都在升级模型。宝玉转述并自测：额度确实又重置了，Antigravity 里可以用 Carbon，但 Gemini 网页似乎还不行；不用 Argon 时，并把进来的那部分额度可以花在 Carbon、Neon 等模型上。Varun 还说，可以把编排模型（做计划、设计和复核）和执行模型（搜索、编辑、构建和测试）分开设置力度，他自己用的是 Neon High 配 Hydrogen High（额度与 Carbon、Argon 额度合并、编排器配对、任务清单、宝玉、宝玉补充）
    前提或争议：升级仍在滚动，有人可能先看到额度重置、后看到模型列表里的 Carbon。累计未用额度（banked resets）Varun 说还在设计，不是已经上线。清单的版本号，TestingCatalog 转述团队成员称 2.34.0 已对所有用户开放，我没有打开应用核对
    为什么值得看：可抄的是分工，不是额度本身：强模型做编排和验收，便宜模型执行，并用清单盯长任务；今天的重置是厂商为换模型做的一次性调整，不能当成稳定的补额机制
  5. Google 官方博客称，Gemini API 现已支持在服务端按页、单元格、时间段和图层切片文件，并可直接上传 Microsoft Office 与 OpenDocument（官方公告，11/24）：Logan Kilpatrick 写，可以把 PDF、Office 文档、幻灯片、表格，以及音频和视频直接交给 API，只请求需要的页面、单元格、片段和图层。官方说明，切片在所有 Gemini 4 模型上可用，上传文件仍受原有大小和页数限制；计费只计算模型实际查看的部分。文档和幻灯片可选页范围、分辨率和文本或页面图像图层；表格可选工作表和单元格范围，并分开要数据、公式还是视觉元素；音视频可按起止时间裁剪（官方博客、Logan）
    前提或争议：这是 Gemini API 的能力，不是 Antigravity 或 Gemini 应用自动具备同样控件；未指定切片选项时，文档和幻灯片默认用保留版式的页面图像，表格会带上所有标签页里的计算值、公式和表名
    为什么值得看：工作台不必再在本地沙箱里用 LibreOffice 或 ffmpeg 切文件；Agent 可以先低成本浏览文本或转写，再对关键页或帧花高分辨率 token
  6. OpenAI 官方教程介绍 Agents API 的时间感知和异步提问：个人 Agent 可以在截止时间前继续干活，不必等用户回完每一问（官方文档，小互于 11/23 介绍）：官方举例，开会前 15 分钟让 Agent 做简报，并留 3 分钟阅读；Agent 若还要确认会议是技术评估还是谈价格，可以用异步工具提问，同时继续检索和起草。时间感知会定期把当前时间告诉模型，剩得多少决定继续深挖还是收束。应用还可设提问截止和全局交稿闹钟：到点仍未回复就交回「未回答」，到交稿点就把最新稿交出去。小互把这两步概括为「看着表干活」和「问完接着干」。示例里需打开 experimental.time_awareness，并使用具备 Agents API 权限的项目（官方教程、小互）
    前提或争议：这是 Agents API 的实验能力，示例模型写的是 gpt-6.2-astra，不是所有 ChatGPT 或 Codex 界面都已同样工作；截止和未回答，要由应用侧实现，不是模型自己保证
    为什么值得看：企业或个人 Agent 只要有「到点必须交货」的任务，可抄两步：周期同步当前时间，提问改成异步，并用闹钟兜底，避免卡在一轮澄清上
  7. Replit 发布 Agent 群体扩展研究，并开源 Optimization-Bench：在固定两小时窗口里，Opus 5.5 对 NumPy 从单 Agent 加速 3.7 倍升到 32 个 Agent 的 18.9 倍；GPT-6.2 Astra 单兵最强，但超过 8 个 Agent 后出现负扩展（厂商研究报告，Amjad 今天转发；报告页标注 11/19）：官方称，与传统扩展不同，加计算不一定更好，组织方式更重要；模型会自发形成不同结构，去中心化的群体比依赖中心协调的表现更好；任务能否并行是预测效果的强信号，单个模型的智力并不是集体智力的好预测指标（研究报告、Optimization-Bench、Amjad Masad）
    前提或争议：数字来自厂商自己的性能优化基准和两小时、受限资源的设定，不能直接推广到所有仓库或所有模型；Astra 在该设置下群体变差，说明不是人多就一定快
    为什么值得看：工作台若要上多 Agent，应先看任务能不能并行，并测量协调成本，而不是默认复制单模型排名
  8. 英伟达董事会宣布，黄仁勋即日起恢复总裁、首席执行官和董事职务（官方公告，北京时间 11/23 晚间）：董事会称表决一致通过，过程中得到美国政府高层意见，并据此认为恢复职务不构成国家安全风险。早前因有报道称黄仁勋成为外国情报工作的目标，董事会已成立全部由独立董事组成的委员会并外聘律师调查；公告写明调查会进行到结束，黄仁勋支持并配合。董事会还新设国家安全与出口管制委员会，并开始招聘向提名与公司治理委员会汇报的首席合规官。Colette Kress 在代理首席执行官之外，将继续担任首席财务官（官方公告、英伟达新闻号、Thomas Wolf 转发）
    前提或争议：调查并未结束；市值因此增加多少，关注名单里出现了约 1 万亿美元和约 3 万亿美元两种第三方说法，口径不一致，官方公告未给出这一数字
    为什么值得看：算力供给和出口合规的人事安排会直接影响模型公司和云厂商的预期，但这是公司治理事件，不等于产品路线已经公布新变化
