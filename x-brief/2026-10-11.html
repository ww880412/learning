技术

  • xiaomovps 发现自己的 Grok Bot 里有一部分内容缺失，查日志发现中间有过一次重置，而官方没有保证数据一定不丢，所以他建议让 Grok Bot 开启定时备份、把重要内容传到 GitHub。原帖
  • xiaomovps 列了 Grok Bot 额度掉得快的三个原因，第一条是 routine 触发太频繁：额度按 agent 步数和 token 算，每小时甚至更短间隔的触发器、或监听很忙的 Slack 频道，可能一天用掉一周额度。原帖
  • AYi 提醒：Claude Code 放进脚本或 CI 的无头模式时，如果不加 bare 参数，会跳过确认直接加载仓库里的 hooks 和 MCP，用在不可信仓库上有风险，建议检查启动参数。原帖
  • servasyy_ai 让 Muse 装 Pi Agent，再通过阿里云中转接到自己本地 V100 上的 Qwen3.8-flash-next，不再受 API 额度限制；AYi 也转述了同一做法，要有一张能跑该模型的显卡。原帖
  • op7418 让 Grok Bot 把一条很长的推文串拉全、补上生僻概念的解释和链接，再排成一篇中文长文，方便在手机上读，你看英文长串时可以照着用。原帖

学术

  • Sakana AI 的 MASS（omarsar0 推荐）：不需要外部验证器，让一个基础模型自己提出多智能体工作流、运行并打分，再用自己的轨迹微调；两轮后 Qwen3.6-27B 在四个开放式基准上的单位输出 token 表现从 1.2 倍提到 1.6 倍。原帖
