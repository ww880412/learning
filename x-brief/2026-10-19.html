MiniMax M3.1 Flash：Space Bunny 原来是它

  • TestingCatalog（@testingcatalog）：官方确认 Space Bunny 是 M3.1 Flash 的早期版本，DeepSWE 74%，每百万 token 输入 0.15、输出 0.60 美元，10 月 23 日放权重，Pro 版也在准备（原帖）；之前他从 API 文档里扒到它主打 100 万上下文和「可调思考深度」（原帖）
  • AYi（@AYi_AInotes）：社区实测生成速度在每秒 85 到 112 token，约为主流大模型的两倍；先匿名在盲测里打出口碑、再官方认领，这种打法很聪明（原帖）
  • 小互（@xiaohu）：之前测过，前端能力似乎是国内最能打的（原帖）
  • LinearUncle（@LinearUncle）：它在 opencode go 上免费 3 天，可以用 Magpie 反代进 Codex 或 Claude Code，和刚升到 1017 版的 DeepSeek Flash 比一比（原帖）

新模型扎堆：Anthropic、Gemini 4 Carbon、OpenAI Terra

  • Stephanie Palazzolo（@steph_palazzolo）：The Information 拿到消息，Anthropic 有新模型，Google 有 Gemini 4 Carbon，OpenAI 可能有新的 Terra 模型（原帖）；随后更正为「接下来几周」，不一定在 10 月内（原帖）
  • 宝玉（@dotey）：据一位用过的人说，Anthropic 这款模型的推理和「直觉」都强过现有模型，话说一半它也能猜到你要什么；Anthropic 没有回应（原帖）
  • TestingCatalog（@testingcatalog）：转发这条消息（原帖），并补充本月早些时候有用户反映 Opus 5.5 会被路由到一个明显更强的模型（原帖），最近也频繁看到 Fable 5.5 的痕迹（原帖）

决策模型：不写文字，只给选项打概率

  • TestingCatalog（@testingcatalog）：Nace AI 发布 Drex Max，能读图片、视频和文字；电脑操作 Agent 每一步发一张截图过去，从固定的动作里选一个，并拿到每个选项的概率（原帖）；OpenAI 平台也上线了 Decisions API 试验场，可以测 Predicate、Choice、Score 三种模式（原帖）

  • 【发布】Skyfall AI 发布工程专用世界模型 SKY-001：据官方测试，CAD 和 BIM 任务上超过 GPT-6 Astra 和 Opus 5.5，速度快约 120 倍——TestingCatalog @testingcatalog（原帖）
  • 【发布】FLUX 3 Max 视频模型：fal 和 BFL 后训练出来的视频模型，效果和 Seedance 2.5 相当，生成最多快 22 倍，支持关键帧、文生视频和图生视频——TestingCatalog @testingcatalog（原帖）

慢下来：别把思考全交给 Agent

  • Thariq（@trq212）：多数同时开一堆 Agent 的人都该慢下来，你做的大部分事其实不重要；先想清楚你的 P0 是什么，如果全神贯注去做会怎样（原帖）
  • 小墨同学（@xiaomovps）：提炼了 Pi 作者推荐的《Agentic Coding is a Trap》：用好 Agent 要有审代码的能力，过度依赖恰恰让这种能力退化；作者的做法是自己亲手写 20% 到 100% 的代码，一次只生成自己审得完的量（原帖）；他也读了 Anthropic 的研究：52 人学写 Python，用 AI 的组快了两分钟，测验分数却更低，差距主要在调试，关键是让 AI 帮你理解，而不是替你思考（原帖）
  • 李继刚（@lijigang）：稀缺能力是能对 AI 的回答说出哪里「不行」（原帖）
  • Viking（@vikingmute）：推荐 Linear 创始人 Karri Saarinen 的《Someone behind the software》：好产品带着创造者的品味，别让 Agent 疯狂加功能，做出没有灵魂的缝合怪（原帖）
  • 【实测】同一个模型，换个 harness 差几十分：DeepSWE 的 113 个真实编程任务上，DeepSeek V4 Flash 在 Codex 里 39%、自家 harness 37%、Claude Code 30%、OpenCode 22%；GLM 5.3 Flash 在 Codex 只有 24%，换到 DeepSeek 的 harness 能到 59%；有自家 harness 的 5 个模型，没一个在自家 harness 里跑得最好——小墨同学 @xiaomovps（原帖）
  • 【技巧】用 pre-commit hook 卡住大文件：Matt 让 Agent 写了个钩子，staged 文件超过 5000 token 就拦下提交，跳过 lockfile 和生成产物，报错里写清楚怎么拆；他补充说只写进 AGENTS.md 不够，Agent 不会总是自觉，文件一大后面就改不好——Viking @vikingmute（原帖）
  • 【消息】OpenAI 开播 Codex 节目 COOKED：第一期讲了 Codex 云端环境（合上电脑任务也继续跑），以及 CLI 的新功能：在终端里和 Codex 说话、追踪各个 Agent、把对话分叉到独立的 worktree——OpenAI Developers @OpenAIDevs（原帖）
  • 【发布】Codex 桌面版可以编辑之前的消息：呼声很久的小功能，他说拖得太久了——Tibo @thsottiaux（原帖）
  • 【发布】Vercel 开源高速 HTML artifact 生成器：基于 libfx，让 Agent 在服务器崩溃、模型不稳、函数超时的情况下也能接着跑，这是他们给 v0 做的底层——Guillermo Rauch @rauchg（原帖）
  • 【发布】Rex 预览版加入前后向 API 兼容系统：这套系统卡住了 Linux 测试，现在又邀请了 1000 位 Mac 测试者，Linux 测试可能本周开始——Mitchell Hashimoto @mitchellh（原帖）
  • 【发布】Pi 社区三件新东西：pi-phone 把 Pi 塞进安卓手机，自带 Linux 环境，App 被杀也能断点续跑；pi-durable-telegram 是 Telegram 里的常驻 Agent；coil 用 Cloudflare Worker 给每条对话配一台带终端和 Chrome 的云电脑——小墨同学 @xiaomovps（原帖）
  • 【发布】阿里通义开源 OpenGCUA：通用电脑操作 Agent 的整套技术栈，包括 harness、跨设备 SDK、原生 macOS 应用、评测轨迹和参考实现——meng shao @shao__meng（原帖）
  • 【技巧】Cloudflare 防天价账单的自检提示词：D1 和 Serverless 用法不对很容易出天价账单，弱模型尤其容易写出循环漏洞；他给了一段只读的计费审计提示词——WquGuru @wquguru（原帖）

一句话：换个 harness 就能差几十分，人自己的审查能力却会越用越弱；与其天天追新模型，不如调好自己手上的工具，并且只放出自己审得完的量。

AI 会替代哪些专业技能

  • Jason Wei（@_jasonwei）：放射科医生不会像大家想的那样被自动化：AI 先擅长常见病，罕见病缺数据，最快也要 3 到 5 年才能从分诊工具走向全自动；更关键的是需求有弹性，读片便宜了，扫描量可能翻几倍（原帖）
  • Nathan Lambert（@natolambert）：一用模型做编程和机器学习以外的事，比如做幻灯片、做连贯的计划、设计较长的内容，就觉得 AGI 还要一阵子（原帖）
  • Ethan Mollick（@emollick）：写好 STATA 代码曾对他的学术生涯很重要，这项技能看起来正在过时；还把 AI 当聊天机器人的学者该注意了，一年里变化很大（原帖）
  • swyx（@swyx）：数据工程师比 AI 工程师吃香，「做 RAG 的」和懂数据密集型应用的人，需求差距是他职业生涯里见过最大的（原帖）
  • 【观点】「计算机不能被问责，所以不能做管理决策」早就不成立：交易、物流、客服、保险里，自动系统一直在做管理决策，假装没有反而是在洗掉责任——Ethan Mollick @emollick（原帖）
  • 【观点】AI 艺术算不算艺术：他整理了 Kelly Boesch 的 TED 演讲：她用 AI 做出怪诞风格的作品，攒下上百万观众，还签了唱片合约；对「AI 用别人的作品训练」，她说自己读美术时也是这样被训练出来的——Frank Wang 玉伯 @lifesinger（原帖）

一句话：判断一个岗位会不会被替代，先看它的需求有没有弹性；放射科和编程变便宜之后需求反而会涨，人做的事会变，但不会消失。
