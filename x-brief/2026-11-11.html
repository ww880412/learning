今日主线
  1. Grok Bot 1.0 正式发布：Bot 可以分享给团队，进 Slack / Teams 群聊，Team、Enterprise、Ultra 套餐还能让它加入 Google Meet、Zoom、Teams 会议并在会后发摘要和待办（官方发布）：官方帖北京时间 11/12 凌晨发出（Grok Bot 原帖、SpaceXSI 原帖、TestingCatalog 原帖）；meng shao 整理的变化：团队共用一个 Team Bot 或只分享给指定人和群，Bot 会主动认领待办、跟进未完成事项，浏览网页更稳，已授权动作少打断、敏感操作仍会问，在公开频道发信息前会检查是否合适（原帖）；小墨同学按官方更新日志列出 0.79 到 v1.0.1 的 5 点：会议、Tailscale 私有网络（连自己的 VPS、NAS、私有 MCP 不用暴露公网）、团队成员可共享部分连接器登录且别人教给 Bot 的知识要管理员或所有者审核才写进团队记忆、Cloud Agent 任务进度在聊天和 Tasks 面板可见、读网页时识别针对 Agent 的隐藏恶意指令并提醒（原帖）
    前提或争议：Team Bot 只给 Team / Enterprise 套餐，会议功能企业版要管理员打开；meng shao 说版本号大约 10 天前就到了 1.0，今天是官方正式宣布。小墨同学另从文档里翻出几个限制：定时或自动触发的后台任务，人工审批卡片 30 分钟过期；自动放行和每次询问规则各最多 20 条，自动放行满了再加会顶掉最早一条，Ask First 优先（原帖）；设置里新增「用量和账单」，可按来源（任务 / 定时例程）或按 Bot 看额度消耗百分比，但没有具体 token 数（原帖）。范凯认为 Grok Bot 用 Opus 5.5、收费接近 Claude 订阅，差价靠 xAI 补，订阅难以长期维持（个人推测，原帖）
    为什么值得看：这是你正在用的工具，团队共享、审核后再写进团队记忆、30 分钟审批过期、规则条数上限，都会直接影响「把 Bot 放进团队群里无人值守地跑」的设计；做工作台时，「别人教的知识要审核才入库」和「读网页防注入」都是可以照抄的做法
  2. 谷歌在 Gemini API 推出 Gemini Decision 1「决策模型」：不逐字生成回答，只对封闭选项打分，一次最多 1000 个问题，每百万输入 token 0.10 美元、输出不另收费，原生支持图像、音频、视频、PDF，256K 上下文，API 可免费试（官方发布）：Logan 原帖；皮查伊说它是在一次推理里给最多 1000 个问题打分（Swaroop 转推 原帖）；Logan 回复称它已在谷歌多个产品内部用上（原帖）；宝玉的中文解读：不写回答只做判断，输出不收钱（原帖）
    前提或争议：价格、上下文和「校准过的判断」都是厂商口径，还没看到第三方对准确率的测试；elvis 说会在自己的研究基准上测（结果未出）
    为什么值得看：工作台里大量调用其实只要「是 / 否 / 选哪个」——路由到哪个模型、这次改动要不要人审、检索结果相关不相关；用打分模型替代生成模型做这类判断，成本和延迟都会降一个量级
  3. Anthropic 把 Fable 5.2 提示指南里的推荐写法改成「你是这个代码库的所有者和长期维护者，设计由你决定」；WquGuru 实测 Fable 5.2 单价约是 Opus 5.5 的 2 倍，建议 Opus 5.5 medium 当主力、Claude Code 里用 /advisor fable 遇难题再开（官方文档改动 + 用户自测）：Simon Willison 发现上期提到的「This codebase is yours」被改写（原帖）；WquGuru 称普通 Python bug 在 medium 档 Fable 花 $1.87、Opus 花 $0.97，high 档差 4.5 倍；Fable effort 建议 low 给需求明确和子 Agent、medium 日常、high 留给难题，xhigh 和 max 别碰；/effort、/advisor off 中途切换不会让主模型的 prompt cache 失效（原帖）
    前提或争议：价格对比和档位建议是 WquGuru 翻官方数据加自测得出的；他另说 Fable medium 和 Opus high 测试成本相近，但 Fable 周限额更紧（原帖），一晚上 Fable medium 跑掉 24% 周额度（原帖）
    为什么值得看：提示词从「代码归你」变成「你是长期维护者、设计由你定」，意思是鼓励模型主动改结构而不是小修小补，用在工作台的系统提示里要配合评审；「主力 + advisor 按需开」是控制额度的现成做法
  4. FrontierHarness v1.1 出了部分结果（测试未跑完）：范凯转述实时榜，Codex CLI 编程通过率最高、token 最少，Pi Agent 其次，Claude Code 照旧很费 token，DeepSeek Harness 效果一般（第三方评测，进行中）：范凯 原帖；榜单覆盖 Claude Code、Codex、Pi、Hermes Agent、Cline、Grok Build、Antigravity、OpenCode、Copilot 等，62 个任务，每个 harness × 模型组合跑满 248 次才算定稿；小墨同学称 Pi 在 21 组 harness 里暂列第二，搭配 DeepSeek 通过率 80.3%（原帖、原帖）
    前提或争议：排名会随运行结果继续变；范凯说自己体感一致，但长程任务 Pi 会偏离、耗时很长，这时换 Codex CLI 更稳（个人体感）
    为什么值得看：上期写了这套评测「换模型要不要换 harness」的设计，今天开始有数：同一模型换 harness，通过率和 token 差得很多；工作台选外壳时，token 开销要和通过率一起看
  5. Tw93 删掉近 1/3 的 Skills、精简所有项目上下文，公开一份让 Agent 自查精简的 14 步提示词（作者实践）：要点是先盘点每轮都会加载的内容（根目录 AGENTS.md / CLAUDE.md、全局规则、没写 paths: 的规则、每个 skill 的描述）占多少字；逐段分成修、删、挪、改写、保留，出清单确认后再动；删掉「你本来就会做」的话，写目标和完成证据而不写路线；偏好、被否掉的方案、不报错的坑、不可逆操作规则、带日期的决策记录不能删；改完让一个没参与的 Agent 只看消失的行去查删过度，并在新位置埋暗号开新会话验证真的会被加载（原帖）
    前提或争议：其中「根目录不要建 CLAUDE.md，它会让 Claude Code 不再读 AGENTS.md」是作者的说法，没看到 Anthropic 文档原文佐证；装了 Waza 的可以直接说「帮我精简一下规则」
    为什么值得看：模型变强后旧规则反而碍事，这份清单可以直接拿来给工作台的 AGENTS.md 和 skills 做定期体检，尤其是「埋暗号验证加载」和「旁人查删过度」两步
  6. OpenAI 发布研究：模型越聪明，越难通过思维链（CoT）监控（官方研究）：Jeffrey Wang 的 10 条长帖说，前沿模型不写 CoT 的推理能力随预训练变好平滑上升，这意味着 CoT 能看到的东西变少；模型按指令操控自己 CoT 的能力也随之变强，RL 过程中即使没有过程监督也会明显上升，而且这种能力能通过蒸馏从老师传给学生（原帖、elvis 推荐 原帖）
    前提或争议：作者自己说在一对能力相近的模型上，没看到「能操控 CoT」和「能躲过监控」有明显关联，认为前者只是后者的一个嘈杂指标；很多问题还没答案
    为什么值得看：工作台如果靠读 Agent 的思考过程来做安全审查，这条研究说明它会越来越不可靠，权限和结果校验还得放在工具层
  7. 两项 Agent 记忆研究都说明「存经验」比想象中难：KAIST 发现记忆会让 Agent 做错本来能做对的题；Unify 的 Continual-ARC 基准上 OpenClaw、Hermes Agent、Prime Agent 都没学到东西（论文 / 厂商基准自报）：KAIST 称原因是只按成功或失败给经验打标签、存下来的「教训」不带原始过程，错了也没法核对；他们的 WikiTrace 把每条教训连到成败原因摘要和原始轨迹，遇到含糊、冲突或来自失败的教训就回去查，在 ALFWorld、AppWorld 等 5 个基准上平均比无记忆高 10.7 分，原本能做对的题失败率从 6.5% 降到 4.5%（DAIR 转述，elvis 转推 原帖）；Continual-ARC 上三个 Agent 既记不住有用的东西也不能泛化到新任务，训练一个 9B 小模型的权重两样都做到了（Jerry Liu 转推 原帖、elvis 推荐 原帖）
    前提或争议：Continual-ARC 是 Unify 自家新基准，结论来自出题方；elvis 认为现在 harness 里的记忆只对简单、一次性的任务管用（观点）
    为什么值得看：工作台的记忆机制可以直接借 WikiTrace 的做法——每条记忆都留出处和原始过程，可疑时回查；也提醒别把「写进记忆文件」当作 Agent 会学习
  8. Anthropic 路演视频说：今年首次接入 AMD GPU，过去上新芯片要几十名工程师干几个月，这次用 Mythos 三天就写出在 AMD 上跑 Claude 的内核；丁一称 Anthropic 下周 11/19 开始公开交易，7 名联合创始人在 IPO 中合计卖出 17.5 亿美元股票（路演视频转述 + 招股书转述）：oran_ge 引用路演视频原话（原帖）；Amjad Masad 也据此称 Anthropic 不依赖英伟达（原帖）；丁一据周二招股书称每名联合创始人净资产约 180 亿美元（原帖）
    前提或争议：「三天」是路演宣传口径，没说内核覆盖多少功能、性能如何；交易日和售股金额是丁一转述招股书，没读到招股书原文
    为什么值得看：顶级模型自己写底层内核、把新芯片接入从几个月压到几天，如果属实，会削弱单一芯片厂的锁定；Claude 的成本和供给可能因此更有弹性
