X 简报 · 11/10（周二）

今日主线
  1. Anthropic 发布 Claude Fable 5.2 / Mythos 5.2：官方称几乎所有评测都高于 Opus 5.5，输出最高快 30%，API 从 $10/$50 降到 $8/$40；日常写代码仍建议先用 Opus 5.5，大而开放的任务再换 Fable（官方发布）：FrontierCode 2.0 上 Fable High 约 45.3%，与 Opus 5.5 Max 的 45.5% 持平但单任务花费约一半；Xhigh 到 49.1%。Claude Code 需 ≥2.1.321；默认 Medium 档；可选快速模式价格翻倍。Mythos 与 Fable 同底座，去掉网安/生物护栏，只给通过验证计划的机构（claudeai 发布、对比 Opus、FrontierCode、定价与上线、何时用 Opus、Mythos 申请、官方博客、宝玉 整理、Addy 原帖）
    前提或争议：数字来自 Anthropic 自家评测与发布文，第三方尚未复现；Addy 提醒虽然单价降 20%，Fable 吃 token 更多，单任务花费往往和 5.1 差不多
    为什么值得看：工作台默认模型策略可以直接抄官方：日常 Opus 5.5，长程大任务手动切 Fable；先升级 Claude Code，再在固定仓库跑同一批任务对比 Medium/High
  2. Fable 额度：Pro 本周可从套餐额度扣（最多一半）并送 1 次免费重置；Max/Ultra/Team Premium 按订阅时长送 1–3 次重置；Alex 给了四条用法（Anthropic 团队说明 + 个人经验）：不满半年 1 次、半年到一年 2 次、一年以上 3 次；重置只退 Fable 已用额度、有 5 小时窗的会补满窗口，不提高周上限。Alex：先问「我的想法哪里不对」、med/high 起步把 xhigh 留给最难题、事先说清哪些操作要批准、给整项目让它连跑几小时（bcherny 重置说明、Pro/Max 细则、alexalbert__ 用法、全项目体检提示、Addy token 提醒、宝玉 体检提示中文、Gorden Sun Pro 本周可用）
    前提或争议：重置资格截止到太平洋时间 11/9 上午 10 点前已付费账号；Pro 优惠到 11/16，之后恢复按量；细则主要来自宝玉对官方博客的整理和 Boris 帖子
    为什么值得看：有 Pro/Max 的可以本周集中跑长任务并吃掉免费重置；工作台提示词库可加「先挑毛病再动手」和「全项目体检」两条模板
  3. OpenAI 开发者号：同一个 dot 可挂多台本地电脑，任务时可指定在哪台跑——一边本机写代码，一边让专用机构建/测（官方功能发布）：举例包括第二台 Mac 用 Xcode 测 iOS 并回传截图、同测用例在新旧 SDK 机器上对比、UI 流程在副机点完再抓失败点（OpenAIDevs 原帖、用法续帖）
    前提或争议：只说明能力，没给延迟、权限模型和稳定性数据；需要已有 Codex/dot 环境
    为什么值得看：和企业工作台「专用验证机 + 开发机分离」同一思路；可以先把验收和截图任务派到副机，本机键盘不被抢
  4. OpenAI Agents API 本周更新（开发者 Mike Luo 发帖，OpenAIDevs 转发）：提示缓存拉到 12 小时、异步工具调用、按会话预算控制（beta）（团队成员帖子，非产品官宣页）：长跑 personal agent 靠 12 小时缓存省钱；异步函数让 agent 发起慢查询后继续干别的；预算控制可限制单会话 token，避免一个客户吃光配额（AzianMike 原帖、OpenAIDevs 转发）
    前提或争议：预算控制仍要私信/邮件申请；异步与缓存的具体配额和定价帖子没写清
    为什么值得看：工作台若接 Agents API，长任务会话应默认开长缓存；后台任务要有 per-session 花费上限，和 Addy 说的「轮数或花费上限」同一类闸
  5. Grok Bot：多位用户证实周额度被免费重置；TestingCatalog 称全体重置且「消耗会明显改善」；小墨把 100 刀降到 30 刀并开始找开源替代（用户体感 + 爆料号，未见马斯克本人新帖）：歸藏、小互、Gorden、范凯都看到用量清零；小墨不满模型路由不透明、额度不透明，点名 OpenBot、OpenMausBot 这类可自选模型并迁移数据的复刻（testingcatalog 原帖、Gorden Sun 原帖、xiaohu 原帖、op7418 质量吐槽、用量、xiaomovps 降级与替代、fankaishuoai 续费观望）
    前提或争议：「消耗改善」只是爆料口径；重置是否改变周上限规则没有官方说明；开源替代成熟度未验证
    为什么值得看：例行任务仍跑在 Grok Bot 上的，先记下重置前后单次消耗再决定要不要迁；知识库和记忆不要只绑一家
  6. Garry Tan 开源 g-harness-evals：同一模型只换 harness（系统提示/工具/记忆），在模拟 Slack 办公任务上看谁更准、谁更省钱（开源评测；作者自报）：模型固定 Opus 5.5 或 GPT-6.1 Sol；准确率各家大约 71%–79%、区分不开，真正差在成本和速度——Opus 上 OpenClaw 约 $0.44/题，其余约 $0.19–0.24；Sol 上 Codex 约 $0.17、约 30 秒（meng shao 解读、仓库）
    前提或争议：20 道开发集已接近饱和，作者承认差距多在统计噪声内；部分 OpenClaw 组合没跑完
    为什么值得看：选型别再只看通过率，工作台对比 harness 应同时报「每题花费 + 耗时」；跨频道纠正这类任务所有 harness 都容易翻车，值得做成固定回归题
  7. Deedy 开着 --dangerously-skip-permissions：Agent 想清掉残留 cat 进程，执行 pkill -f "cat"，结果匹配到 Applications 里带 cat 的路径，把 Mac 上正在跑的应用全杀了（作者自述）（deedydas 原帖、确认未人工批准）
    前提或争议：单一事故；根因是跳过权限确认 + 过于宽的进程匹配
    为什么值得看：工作台默认拒绝宽 pkill/kill 模式，危险命令必须人批；「跳过权限」不能当日常模式
  8. huangserva 称自己被灰度到 GPT-6.2，Three.js 审美「绝了」，并给了不联网探测提示；与上期 OpenAIDevs「Tomorrow.」预告相接（个人实测，官方仍未点名 6.2）（servasyy_ai 原帖）
    前提或争议：只是个人路由体感；OpenAI 仍未发 6.2 说明；探测法不能当正式版本身份证
    为什么值得看：Codex 默认模型若在灰度，可用自己仓库里的固定前端任务做前后对比，不看榜
