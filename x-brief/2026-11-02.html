X 简报 · 11/3（周二）

今日主线
  1. Claude API 上线「消息线程」公测（官方已发布）：长对话每轮只发新消息，Claude Code 已对多数用户默认开启：Anthropic 北京时间 11/3 凌晨宣布，Messages API 加一个 thread 参数后，服务器把对话暂存在内存里，下一轮只发新消息和上一条回复的 ID。官方称 Claude Code 默认开启后，50 万到 100 万 token 的请求首 token 等待中位数缩短约 35%；宝玉整理的官方数据是长对话单次请求中位数从约 800 KB 降到 1.8 KB（ClaudeDevs 原帖、宝玉 原帖、官方博客、文档）
    前提或争议：只省上传和等待，不省钱：Claude 每轮仍读完整对话，token 和价格不变，提示词缓存还得自己设。线程 5 分钟没新请求就过期、返回 404，本地必须留完整记录重建；中途不能改系统提示词、工具、模型和思考设置；要带 beta 头 message-threads-2026-08-12；宝玉提到不支持零数据保留（ZDR）和 HIPAA，批处理接口也不支持
    为什么值得看：工作台如果直接调 Claude API 跑长会话 Agent，这是最便宜的提速：加一个参数、处理一次 404 重放。但企业客户要求 ZDR 的场景不能开，开关要做成按租户配置
  2. DeepSeek Search / Fetch 结束免费：经 Claude Code、Codex、DeepSeek Harness 打出去的联网工具调用，北京时间 11/1 起按次收费：官方文档写明两个接口各按每千次成功请求 $0.75 计费，与返回条数和 token 无关；失败、空结果、超时不收钱；Search 每账号 100 QPS、Fetch 25 QPS。meng shao 换算：Agent 一天打 1 万次成功搜索约 $7.5，不含模型 token（meng shao 原帖、官方计费文档、价格页）
    前提或争议：只影响用 DeepSeek API key 跑这些工具、且开着联网工具的情况；直接调接口一直是收费的。扣费先用赠送余额，余额不足返回 402。官方文档已确认，不是转述
    为什么值得看：如果你在 Claude Code 或 Codex 里接了 DeepSeek 模型做便宜的子任务，现在模型账单之外多了一笔工具账单。工作台的用量面板要把「工具调用次数 × 单价」单独列出来，循环搜索的 Agent 要设次数上限
  3. Vercel 构建默认拦截已知恶意 npm 版本：安装前查锁文件，安装中拦下载，不用配置：Vercel 11/2 更新日志称，所有套餐的新构建都会对照一份恶意或有漏洞的包版本黑名单，在依赖安装前检查锁文件（包括从构建缓存恢复的依赖），安装时拦截受影响的公共 npm 下载，命中就让部署失败、报出包名和版本，并尝试清掉受污染的构建缓存；Rauch 说目的是在 install 脚本运行前挡住，防止代码和密钥被偷（Rauch 原帖、vercel_dev 原帖、Vercel 更新日志）
    前提或争议：官方已发布；只拦黑名单里「已知」的版本，新规则一般几分钟内生效，对还没被发现的投毒包没用；只管 Vercel 上的构建，你本机和 Agent 沙箱里的 npm install 不在保护范围
    为什么值得看：Agent 装依赖是工作台最容易被供应链投毒的环节。可以照抄这两步：装依赖前先拿锁文件对一遍黑名单，装的过程中走一个能拦截的镜像代理；命中就停，不让 install 脚本跑
  4. Google 开源 Elephant-Goldfish：「大象」带着上下文写方案，「金鱼」不看聊天记录专门审方案：GitHubDaily 介绍，熟悉项目背景的「大象」Agent 起草设计，没看过前面对话的「金鱼」子 Agent 只拿方案和相关资料审查：需求说没说清、漏没漏关键条件、照着做会遇到什么问题。官方博客和仓库写明流程是讨论 → 起草 → 审查 → 人批准 → 实现，审查分五个阶段，问题按 blocker / major / nit 分级，带 7 个 skill，支持 Claude Code、Codex、Antigravity（GitHubDaily 原帖、仓库、Google 开源博客）
    前提或争议：是 Google 开源的流程插件，不是评测过的方法，没有效果数据；审查意见采纳哪些仍由人决定
    为什么值得看：和你「Claude Code 出方案、Codex 实现」的分工能直接接上：方案写完先派一个零上下文的子 Agent 按固定清单审一遍，聊天里说过、文档里没写的前提会被它当场揪出来。工作台可以把「无上下文审查」做成方案阶段的固定一步
  5. 有人发现自己的 Agent 几乎从不用 MCP：卡在得有人先装连接器，Agent 直接改调 API 或开浏览器：levelsio 转引 Steve Lacey：他的每个 Agent 是一个 Claude Code 会话，有自己的项目目录和 .env 密钥，只交代目标；结果 Agent 几乎不选 MCP，甚至悄悄绕开他专门为它们写的 MCP 服务。原因是多数环境里连接器要人去点安装配置，Agent 做不了这步。他认为 MCP 留下来的价值是「没有契约的 API」：Agent 每次读最新说明，接口可以随时重写（levelsio 原帖、Steve Lacey 原帖）
    前提或争议：个人经验，没有统计数据；他的 Agent 有现成 API key，换成只给 MCP、不给密钥的环境结论未必成立。levelsio 认为长期看 MCP 和 API 会合并，同时支持 API key 和 OAuth
    为什么值得看：工作台给 Agent 接工具时，别默认「做了 MCP 就会被用」。可以抄的一步：在 Agent 的日志里统计每个工具的实际调用次数；连接器的安装和授权要能由 Agent 发起、人只点一次批准
  6. OpenAI 为 Codex 带来的并发重做 Git 后端 Pando：推送延迟中位数降近 5 倍，每天出近 1 PB 数据：OpenAI 11/2 博客称，Codex 让工程师并行开很多改动，每次 push 又触发多个 CI 任务拉同一提交，monorepo 一度可靠性跌到 90% 以下。Pando 保持 Git 协议和客户端不变，两点改动：每个分支独立协调更新，不同分支的 push 并行；多个客户端复用同一批 packfile，像 CDN 一样服务读取，代价是客户端可能下载已有对象、同时看几个分支时各分支时间点可能不一致。修复也回馈了上游 Git（OpenAIDevs 原帖、原帖、Tibo 原帖、OpenAI 博客）
    前提或争议：官方称的数字，没有外部基准；这是 OpenAI 规模（单一 monorepo、海量 Agent）的问题，Pando 本身没开源，开源的只是对 Git 客户端的补丁
    为什么值得看：多 Agent 并行开分支后，瓶颈会从「模型够不够聪明」移到 Git 服务和 CI。工作台在设计并发 Agent 数时要把 Git 托管的推送并发和 CI 排队算进去，按分支隔离写入这一点自建也能先做
  7. MIT 用 GPT-6 Astra 直接改小模型权重：只动 Qwen3.5-0.8B 的 0.016%，MATH-500 从 7.9% 到 48.1%（作者自报）：MIT CSAIL 四位研究者 11/2 发博客，把这叫「权重空间编程」：不训练、不算梯度，让 Astra 读原始权重、按自然语言目标改。Qwen 那次 Astra 在 Python 环境里对着权重，用 50 次练习题前向，定位到第 15、19 层 MLP 里导致思考死循环的一个方向并删掉，共改 131,072 个权重；GSM8K 13.8%→67.1%，IFEval 21.0%→62.3%，答到长度上限的比例 93%→33%（宝玉 原帖、rikiyatakehi 原帖、MIT 博客、实验日志仓库）
    前提或争议：作者自报、日志全公开；6 倍主要来自修掉原模型已知的死循环（Qwen 模型卡就警告过），只给 10 或 25 次前向时循环基本没消失；换成很少循环的 Gemma 3 270M 几乎没提升，作者也说这是「去掉障碍」，不是加出新能力。日志显示 Astra 是通过 Codex CLI 调用的
    为什么值得看：离工作台还远，但给「Agent 改进 Agent」开了新方向：以后能被 Agent 改的不只是提示词、skill 和 harness，可能还有本地小模型的权重。眼下可抄的是它的实验设置：固定前向预算、测试集对 Agent 不可见、全部日志可复查
  8. Anthropic 更新招股书：三季度收入约 170 亿美元，环比涨 47%，算力和基础设施承诺 8954 亿美元：Anthropic 11/2 提交 S-1/A：Q3 收入 169.56 亿美元，同比约 12 倍；前三季度 332.4 亿；未来 12 个月要付 698 亿算力承诺；Q3 算力成本 98.63 亿（含 50 亿短期算力），经营亏损 5.67 亿。文件还写到，内部对未来模型的估计显示可能「很快」达到 RSP 里「AI 带来的显著加速进展」门槛。Gary Marcus 引用的数字是 Q3 收入环比涨约 47%、算力和基础设施支出涨约 78%（SEC S-1/A、CNBC 报道、Gary Marcus 原帖、原帖、Mollick 转推、deredleritt3r 原帖）
    前提或争议：收入和承诺数字出自官方文件；「Q3 不如 Q2、离财务灾难不远」是 Gary Marcus 的看法。RSP 那句只说未来模型「可能」达到门槛，媒体报道称 Anthropic 还没有认定任何现有模型越线；「2 倍进展速度」的换算是 deredleritt3r 自己的解读
    为什么值得看：你每天用的 Claude 背后是近 9000 亿的算力合同和仍在亏损的利润表，价格、额度和套餐还会继续调整（上周 Max 改名 Ultra 就是一例）。工作台的模型路由要能随时换供应商，不要把关键流程绑死在一家的套餐额度上
