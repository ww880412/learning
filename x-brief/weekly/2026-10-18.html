升温

1. 开放权重模型回潮，而且越来越便宜

这周先是 Meta 放出 Muse Spark Open，再是 Reflection 的 Beam，周末 DeepSeek V4.1-Flash-1017 刷屏。讨论从「跑分超过 Opus 5」转到「实测不如 Opus 5.5，但便宜很多」，到周日已经变成「单卡能跑、成本约八分之一」，还有人说重心正在从预训练转到后训练。

  • 差距缩短一半：Muse Spark Open 发布后，他认为美国开源和中国的差距至少缩短一半——Nathan Lambert @natolambert（原帖）
  • DeepSeek 新版跑分：DeepSWE 1.1 得 77%，超过 Opus 5，价格极低——TestingCatalog @testingcatalog（原帖）
  • 同一任务成本约八分之一：转述的对比是 GPT-6.1 Sol 花 6.10 美元、5 分钟，DeepSeek 新版花 0.78 美元、3 分钟——AYi @AYi_AInotes（原帖）

2. 换 harness、让大模型调度，比换模型更划算

周初是论文说同一个模型换一套 harness（模型外的提示词、工具、记忆）能差一个数量级；周中变成实战派的共识：让 Opus 这类强模型拆任务和验收，便宜模型干活；周日 Google 开源 Harness²，让 Agent 自己改 harness。争论的方向从「哪个模型最强」移到「怎么搭配和调教」。

  • LongHarness：同一个 GLM-5.3-Flash，换 harness 后精确匹配从 4.4% 涨到 61.1%——elvis @omarsar0（原帖）
  • 最好的模型当调度：长程任务里小误差会层层放大，所以前沿模型不容易被便宜模型替代，应该让它来编排——Ethan Mollick @emollick（原帖）
  • Harness² 两层循环：越弱的模型获益越大，改好的 harness 比 Claude Code、Codex 的固定 harness 高 4.6 到 5.8 分——meng shao @shao__meng（原帖）

3. Agent 涌进现实服务，对面开始设防

从 Agent 编队绕过高德反爬，到 X 评论区被 AI 回复淹没，再到航司、银行、电商封堵 Agent，这条线一周里越来越具体。说法从「将来会冲击」变成「已经在冲击」，周末的分歧是该封还是该找安全的协作方式。

  • Agent 编队绕过高德反爬：被拦后手法逐级升级，还用上了泄露的 key——yibie @yibie（原帖）
  • 一句提示注入劝退评论机器人：发帖让 AI 留下 API key，帖子下的 AI 评论几乎没了——向阳乔木 @vista8（原帖）
  • 网站开始封堵 Agent：他认为一禁了之不是稳妥办法，长期要找安全的协作方式——Ethan Mollick @emollick（原帖）

4. 蒸馏攻防从指控变成安全事件

周二 Anthropic 点名智谱和月之暗面蒸馏 Claude 的思维链，周四 FT 报道 5%–7% 营收来自被蒸馏，周五 Anthropic 公开三层防御，周六 OpenCode 因「蒸馏攻击」泄露了用户密钥。讨论从「谁在偷」走到「这个词是不是被用滥了」。

  • 点名两家：几十万个假账号通过代理向 Claude 发了数百万次请求，目标是完整思维链——AYi @AYi_AInotes（原帖）

  • 盗密钥也叫蒸馏？：他觉得把盗 API 密钥的网络攻击归进「蒸馏」很奇怪——Nathan Lambert @natolambert（原帖）

类别迭代

固定 8 类从 10/17 才开始用，这周只有 2 期样本，「其他」里记了 6 条。两期里 8 类都有内容，没有空类。下面是两条提议，只是建议，你同意了我再改 categories.md。

提议一：新增「AI 与社会」

AI 对工作、学习和学术生态的影响类观点反复出现，现在要么掉进「其他」，要么被塞进不太对的类（「研究」里放了不是论文的观点，「安全与政策」里放了奇点和学术伦理）。建议新增一类，收 AI 怎么改变工作、学习、公共服务和学术圈的观点，不收具体工具和产品。理由是这 5 条：

  • 已在「其他」：60 分是新的 0 分（原帖）；别让 AI 直接给答案（原帖）
  • 放在「Agent 与编程」：软件工程全自动化后大家从没这么累过（原帖）
  • 放在「研究」：Agent 正在冲垮办事门槛，这是观点不是论文（原帖）
  • 放在「安全与政策」：陶哲轩说 AGI 竞赛变得有毒（原帖）

提议二：用 AI 做出来的个人作品，统一归「产品与应用」

「用 AI 做了个什么」的趣味实测这周散在三个地方，建议在归类规则里加一句：个人用 AI 做出来的作品和玩法归「产品与应用」，讲开发流程和工具才归「Agent 与编程」。理由是这 4 条：

  • 已在「其他」：能开的 Roadster 模拟器（原帖）；Claude 搭出来的个人主页（原帖）
  • 放在「Agent 与编程」：20 分钟给儿子做了个打字游戏（原帖）
  • 放在「产品与应用」：让 Fable 5.1 把博尔赫斯的小说做成 3D（原帖）

剩下的国家域名经济（原帖）和 526 种中国传统色（原帖）和 AI 关系不大，继续留在「其他」就好。
