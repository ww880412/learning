#1

DeepCell

Your deadline survival kit for office work
新发现
开发者工具AI工具效率
是什么
面向截止日期的办公套件：用自研 .deepcell 格式把推理备忘（cheat sheet）、表格、文档、幻灯片连成一份，改一处可联动相关内容；提供 Web、Claude Code 插件、CLI 和远程 MCP。
解决
建模、销售复盘、预算、月报这类「要算又要讲」的活，散落在 Excel/Word/PPT 里，改数字后叙述和幻灯对不上，还难向 AI agent 讲清结构。
亮点
官方提供给 agent 读的安装说明（for-agent.md）；插件仓库 deepcell-ai/deepcell-plugins；可导出 Excel/Word/PPT/PDF。当日综合分榜第一。
启发
两层可抄：一是「给 agent 一份自描述安装文档 + CLI/MCP/插件三通道」的接入方式；二是把可计算表格和可叙述材料绑在同一真相源，企业工作台做报表/评审材料时可参考这种联动格式，而不是让 agent 分别改三个 Office 文件。

#2

Claude Duet

Proactive agent that understands what needs your attention
新发现
coding agentAI工具效率
是什么
Anthropic 的主动式 agent 应用：连上邮箱、日历等应用后，每天早上发简报，白天只在需要你决策时找你；任务在云端虚拟机里继续跑，发消息、付款、签字、删除前会先征求批准。
解决
专业人士和小企业主每天要盯的事太多，被动聊天式 AI 要人主动去问，容易漏掉日历冲突、待回邮件这类「该提醒你」的事。
亮点
研究预览阶段，对美国 Pro/Max 用户开放候补；沿用 Claude 的 memory、skills 和 Marketplace 连接器；凭证按 Claude Managed Agents 设计、agent 看不到密码；另有敏感信息分类器。获当日 Launch of the Day。
启发
企业级 coding agent 工作台最该抄的是「主动注意力」和「高风险动作必批」：后台定期扫连接的系统，只把阻塞推给人；发送、付款、删改走审批。云端 VM 持续干活、本机关机也能跑，是长任务 harness 的产品形态参考。

#3

Doneas

A daily accountability call with other entrepreneurs.
新发现
效率
是什么
给独立开发者/创业者的问责圈子：周一锁定本周计划，工作日与固定的另外五人开 15 分钟站会，汇报完成项、下一步和阻塞，并在公开进度页记下交付。

#4

heal.dev

Find bugs and vulnerabilities code review misses
新发现
coding agent开发者工具AI工具
是什么
运行时 QA agent：先学会怎么跑你的应用，搭一个把外部服务 stub 掉的类生产沙箱，再主动挖会真正打到用户的 bug、性能回退和运行时漏洞；每条缺陷先复现再报，并给出失败测试。
解决
Code review 和静态分析只看 diff，coding agent 写的 e2e 也多走 happy path；真正在运行时才炸的问题仍会进生产。
亮点
官方称约 70% 的发现是代码评审机器人抓不到的；可把缺陷交给 coding agent 经 MCP 处理后再跑一遍验证；beta 免费、不用绑卡。
启发
工作台可把「运行时复现 + 失败测试」做成 agent 交付闭环的一环：修完代码不是开 PR 就完，而是在沙箱里复跑直到绿。MCP 把找 bug 和修 bug 串起来，正好补企业 coding agent 的质量门禁。

#5

Mistral Voxtral 3

Mistral’s speech models for transcription, TTS and agents
新发现
AI工具
是什么
Mistral 新一代语音栈：转写（含说话人分离、时间戳、end-of-turn）、TTS（情感/语速/强调、音色克隆）以及把听、想、调工具、说串起来的 Voice Agent SDK。
解决
做实时语音 agent 通常要自己拼 STT、LLM、TTS 和电话/浏览器通道，多语言和延迟也难控；企业还常要数据留在自有环境。
亮点
转写宣称 50+ 语言；TTS 支持 35+ 语言；可通过 Mistral 欧盟托管 API 或自有基础设施部署（权重是否开源未在公开页标明为 HF 开源；旧版 Voxtral Mini 曾有 Apache-2.0）。公开预览。
启发
工作台若要加语音入口（走动口述任务、会议交接），可直接评估这套「听-推理-工具-说」一体 SDK，而不是自拼四段管道。端到端与可自部署对政企场景是加分项。

#7

Loom Record for agents

Hit record and hand off to AI, now in the new Loom app
新发现
coding agent开发者工具效率
是什么
Loom 新的「给 agent 录」模式：边说边指屏幕，自动把语音、点击、选中的 UI、访问过的链接和关键帧合成结构化 agent prompt，可交给 Claude、Cursor、Rovo、ChatGPT 等执行。

CutBay

AI Video Agent: Turn Anything into Videos via Chat
新发现
创作AI工具
是什么
聊天式 AI 视频 agent：用一句话、链接、文档、PDF、演示稿、表格或素材生成视频，再通过对话改脚本、画面、配音和字幕，不必自己拖时间线。

#10

Resend Inboxes

Create shared inboxes, connect your agents, build workflows
新发现
coding agent开发者工具AI工具
是什么
面向人和 agent 的共享收件箱：在自有域名上建地址，邮件按线程组织，团队可分配、留备注；同一收件箱可被人与 agent 并肩处理，并提供 API、CLI、远程 MCP。

启发
企业工作台里「每个 agent 一个邮箱地址收任务/审批」是很干净的外部通道。可抄：线程原语 + 人机共治 + 动作白名单逐步放权。接 MCP 后，夜间摘要、草稿回复都能接到现有 coding agent 上。

#7

Notion Auto

Notion’s rebuilt Agents run for hours and cost far less
新发现
AI工具效率
是什么
Notion 重做了 Agents 的 harness：任务可跑 24 小时以上，自带电脑和浏览器，新的 Auto 模型路由按任务难度选模型。
解决
原来 Notion agent 只能跑约 5 分钟，长任务做不了，成本也高。
亮点
新增「Review for me」模式，由另一个模型在 agent 动手前检查操作；Auto 路由简单请求走快模型、难的走强模型，卡住会换模型，Notion 称在 20+ 常见任务上与 Opus 5.5、Astra 持平而成本约低 90%；可接 ChatGPT 套餐，Notion MCP 重做，改为统一积分计费。
启发
工作台可以直接抄三样：动作前由第二个模型审一遍的安全模式、按难度路由模型控成本、统一积分计费。也说明大厂在把知识库和长任务 agent 合在一起，企业知识库方向值得盯。
