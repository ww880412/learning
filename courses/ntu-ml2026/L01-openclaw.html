这讲一句话讲什么？

OpenClaw 是 AI Agent 里不是 AI 的部分

OpenClaw 跑在你的电脑上，负责记忆、任务管理和操作电脑；聪明程度取决于背后接的语言模型。

过去的 AI「只动口不动手」；Agent 能自己上网、做投影片、配音、上传影片。

  • 讲者的 Agent 叫「小金」，自己开了 YouTube 频道并上传介绍 AI Agent 的影片（课件 p5–6）。
  • 本讲六个问题：怎么知道自己是谁、怎么用工具和 SKILL、怎么记忆、怎么定时工作、怎么长时间自主运作（课件 p16）。
  • 免责声明：OpenClaw 是开源专案，随时在变；本课以概念为主。
  • 官方材料：intro.pdf / intro.pptx；影片 youtu.be/2rcJdFuNbZQ（83 分钟）。

底下的语言模型在做什么？

语言模型只做文字接龙，输入长度有上限

外界给一个 prompt，语言模型一个一个接 token，接到结束符号就停；呼叫者不一定是人。

讲者：输入越长，就算还没到上限，往往也无法准确接龙；3/20、3/27 再回到这个主题。

  • 上下文窗口（输入加输出的长度上限）每个模型不同；今天较好的模型可以输入上百万 token（课件 p19）。
  • 讲者：了解 Agent 原理后，你会发现上百万 token 嫌少（影片 24:01）。
  • 衔接（补充）：这就是 CS146S 第 1 讲的智能体循环里被反复呼叫的那一步。

每次呼叫都附上同一份系统提示词

系统提示词（每次呼叫语言模型都放在最前面的文字）由多个 .md 文件拼成。

Agent 怎么用你的电脑？

语言模型只输出工具指令，电脑执行

系统提示词写明「想读文件请用 Read」；语言模型输出 [tool_use]，OpenClaw 在电脑上执行，再把结果接回去。

语言模型之所以知道有 Read，是因为系统提示词里写了。

防线要设在 OpenClaw，不只靠提示词

OpenClaw 多数时候用 exec 执行「任何」shell 指令；输出文字指令正是语言模型擅长的事。

讲者：OpenClaw 对指令完全没有智慧，语言模型叫它 rm -rf 它就执行。

子代理省的是什么？

子代理把繁琐过程挡在主上下文外

子代理（用 sessions_spawn 工具召唤、只带精简系统提示词的 Agent）背后是同一个语言模型。

差别在主 Agent 的上下文窗口里只有摘要，没有网页互动和论文全文。

  • 子代理也是工具，所以子代理也能再召唤子代理，层层外包（课件 p39）。
  • 讲者的处理：在子代理那一层直接禁用 Spawn 工具；这样没法靠 prompt injection 骗过它（课件 p41，影片 53:00）。
  • 讲者把这类节省上下文窗口的技巧叫 Context Engineering，下一讲展开。

SKILL 是什么、怎么加载？

SKILL 是按需读取的工作 SOP

系统提示词只列 SKILL 名字和路径；需要时语言模型用 Read 读 SKILL.md，再照流程做。

把 SKILL.md 放到指定位置就有新能力，所以网上下载的 SKILL 要小心。

  • SKILL 不是程序，是流程；可以由 Agent 自己写，例：「回忆怎么做影片，写成 SKILL」（影片 53:00）。
  • 做影片 SKILL 的流程：脚本 → HTML 投影片 → 截图 → TTS 配音 → ASR 验证 → FFmpeg 合成（课件 p44）。
  • clawhub.ai 可以交换 SKILL（课件 p46）。

跨对话的记忆从哪来？

没有调用编辑工具，就没有记住

AGENTS.md 告诉 Agent「每次醒来都是新的」；什么时候写记忆文件、写什么，由语言模型决定。

讲者：只要没开工具去编辑 .md 文件，无论它说什么，都是「记了个寂寞」。

  • 检索：语意比对加字面比对，取最相关的前 K 个 chunk（课件 p52）。
  • 讲者发现较弱的模型更常光说不练（影片 65:00）。

没人说话时，Agent 怎么继续工作？

心跳和 Cron 定时戳醒 Agent

心跳机制每隔固定时间请 Agent 读 HEARTBEAT.md，没事就回 HEARTBEAT_OK；Cron 在指定时间送一段指令。

长时间运行时上下文窗口终究不够，OpenClaw 会把旧对话压缩成摘要，但不压缩系统提示词。

  • HEARTBEAT.md 可以写得不明确，例：「向目标迈进」（课件 p55）。
  • 例：NotebookLM 生成投影片要 3–5 分钟；讲者在 memory.md 写「看到生成中就设 3 分钟后的 Cron」（影片 71:01–73:00）。
  • 压缩方式：反复摘要（Compaction）；裁剪工具输出：Soft Trim 留头尾，Hard Clear 换成「这里曾经有个 Tool output」（课件 p56–58）。
intro.pdf p54–58；影片 66:01–76:00、79:00
失败：「AI 删邮件事件」怎么发生的？

只在对话里说的规则，压缩后会消失

一位 Meta 研究人员要 OpenClaw 删邮件前先问他；做着做着，它没经同意就开始删。

讲者的技术解读：压缩不碰系统提示词，所以规则要确认真的写进 MEMORY.md。

  • 讲者：也有可能这位研究人员是故意演给大家看（影片 78:00）。
  • 讲者的结论：给 Agent 安全的环境（新电脑或格式化的电脑）、教它安全准则、检查它做了什么、不给它平常用的帐号密码（课件 p60）。
  • 讲者把 Agent 比作学生、实习生：会犯错，但不给机会就学不会（影片 80:00–81:01）。
