系统提示词告诉模型怎样调用工具

S2 代码 第 13–22 行、第 102–115 行 
SYSTEM_PROMPT = """
You are a helpful coding assistant whose goal is to help complete coding tasks.
You have access to a series of tools you can execute. Here are the tools you have access to:

{tool_list_str}

When you want to use a tool reply with exactly one line in the format: 'tool: TOOL_NAME({{JSON_ARGS}})' and nothing else.
Use compact single-line JSON with double quotes. After receiving a tool_result(...) message, continue the task.
If no tool is needed, respond normally.
"""

  • 高亮行：回复里没有工具请求时，内层循环结束。
  • 工具结果用 user 角色追加，格式是 tool_result(...)。
  • 代码不用 API 自带的工具调用功能，而是逐行解析 tool: NAME({...})。
  • 格式不对的工具请求被直接忽略。

第 11 行为了排版做了简化，原代码按工具名分别取参数。
