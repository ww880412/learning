CS146S · 10/6 Agent Skills 最佳实践：四类常用 skill 与七条写法

上一讲说 MCP 适合接第三方服务；这一讲讲另一半：LLM 非常擅长照着较长的流程做事，把这种能力暴露出来是任何 harness 的重要部分——这就是 agent skill。课件把常用 skill 分成四类（理解代码与规划、验证、代码风格、其他如浏览器解析），并给出七条写法：范围要专注、自己维护一套可跨项目带走的 skill、从自己的对话记录里挖、用 CLI 加 skill 包住样板、写明触发场景、渐进披露、维护一个验证 skill。课程网站这一讲只放了课件、没有讲课实录，所以本页只讲课件上写着的内容，现场 demo 演示了什么未确认。
