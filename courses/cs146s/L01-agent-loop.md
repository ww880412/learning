# CS146S 2026 秋 第 1 讲：200 行手写一个编程智能体
日期：2026-09-22（原课）｜学习日期：2026-10-11

## 一句话
编程智能体就是一个循环：模型决定下一步 → 调用工具 → 看结果 → 再决定，直到任务完成。

## 怎么运作
1. 把用户任务 + 系统提示词 + 可用工具说明发给模型
2. 模型要么直接回答，要么返回"我要调用某个工具，参数是……"
3. 程序真的去执行（read_file / write_file / edit_file / bash）
4. 把执行结果追加进对话，再发回模型
5. 重复，直到模型不再调用工具

## 为什么要这样
模型本身只会生成文字，碰不到你的电脑。工具让它能"动手"，循环让它能看到后果并修正，像人写代码一样边做边改。

## 例子
任务"修复测试失败"：跑 bash `pytest` → 看到报错 → read_file 看源码 → edit_file 改一行 → 再跑 pytest → 全过 → 结束。

## 小测
1. 去掉"把结果追加回对话"这一步，会发生什么？
2. 为什么 4 个工具里，bash 最强也最危险？
3. 模型怎么"知道"有哪些工具可用？
