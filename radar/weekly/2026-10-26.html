北京时间 2026-10-26 发布；星数、创建日期、License 均为当天 GitHub API 实测，日期按北京时间。标「自报」的数字都没有复现。

一、本周各方向的新东西

端侧 harness / 工作台

  • PandaCode：10-18 创建，★672。和我们最接近的开源工作台：用三种协议接入十几家 CLI（ACP 接一大批；Pi 走 RPC，再用本地桥注入工作台工具；Meta Muse 走 MSP）。带「架构师 + 最多 3 个 worker」的团队、每个任务一个 worktree、多家云沙箱。License 是 MIT 加署名要求。
  • Harp：10-20 创建，★617，AGPL，只能借鉴设计。Warp 终端的分支，用侧栏显示每个会话的状态：工作中 / 等你 / 完成。分组状态存在 tmux 上，重启后还在；额度环读的是会话日志，不碰凭据。
  • 闭源动态：
    • Claude Duet：主动式 agent，研究预览。
    • Claude 各端本周起默认 auto mode：由自动检查拦截高风险动作，不再逐步请人批准（官方状态帖）。
    • Cursor 可以操控电脑，自己驱动 iOS 模拟器测试。
    • Devin Desktop 改版为 agent 指挥中心。

插件 / Skills / MCP（DSH 生态）

  • devin-vuln-fixes：Cognition 官方，★8。一份 skills/ 目录配 5 家清单（Claude、Codex、Devin、Factory、通用），是「一份 Skill 配多家清单」的分发样本。每个 Skill 走同样五步：只读盘点 → 审批 → 补到核实过的版本 → 补丁前后各跑一次测试 → 每个仓库一个 PR。
  • MCPtoCodeMode：★9。把 N 个 MCP 服务器收成 3 个工具，模型写代码在沙箱里批量调用。
  • hermes-labs-plugins：★124。Nous Research 把插件分成「官方 / 实验社区档 / 待认领」三档管理。
  • DSH 新插件（下载量来源均为 npm 下载 API，周窗口 10-16~10-22）：
    • dsh-team-space：★20。局域网团队空间，三种接入：浏览器免安装、Codex 远程 MCP、DSH 插件。不在 npm 上，没有下载数据。
    • dsh-cockpit：★22，周下载 34。多 agent 指挥台，会标出两个 agent 写同一批文件的「双写风险」。
    • dsh-block-ptc：★100，周下载 670。
    • 热门插件 dsh-im：周下载 15,232，月下载 60,318。
  • 插件总量各方说法不一，都列出来：
    • DSH 官方格式索引（dsh-plugin-catalog）实测 3,540 条，只收发了 npm 的插件；
    • awesome-dsh-plugin（★20,696）索引目录下有 6,896 个文件；
    • dsh-market README 自报 4200+；
    • @aigclink 帖称 6000+。
  • 风险：破甲插件 dsh-purge 宣布 10-27 闭源，来自 X 帖，未核实。

上下文与记忆

  • Aletheia：★9。每条记忆都带代码锚点（函数、行、文件），召回时机械复核，失效的不进上下文，不调模型。和库里已有的 dsh-memory-gate（#215，「检索到 ≠ 注入」）组合，就是企业记忆层可靠性的底线。
  • stalemap：★103。找出模型训练截止日期之后变了的依赖，从三处告诉 agent：写进 AGENTS.md 的笔记、编辑后的类型检查报错、一个 MCP 查询工具。

代码知识库与企业资产

  • 没有够格的新开源项目。Vesalius 没有 License，不收。
  • 方法：Jacob Gold（Graphite 转到 Cursor Origin）主张「别审 PR，让机器验证，人只拍板」；他说 Origin 的定位是「代码库即上下文 / 代码托管即 harness」。来自你 10-25 转发的长文。

编排与多 Agent

  • Reason Network：10-16 创建，★1,233。同事之间的 agent 端到端加密直连，每个 agent 只多 3 个工具：list_team / send_message / ask_user，外加「一台电脑只能代表它的主人」的身份证明（src/proof.rs）。
  • pi-pstack：★28，npm 周下载 995，来自你的转发。写代码、只读审阅、跑测试验证三个角色分开，各用各的模型。
  • lights-on-software-factory：★100。用确定性的编排器调度任务，容器里跑 agent，lint 做成 hook；「token 省约 80%」是作者自报。
  • 本周热词是「软件工厂」：Matt Pocock 的 software factory skill（PR #1316，未合并），Qodo 创始人提的「有边界的 L4」。

沙箱与执行环境

  • INVARIANT：★107。给每个项目一个持久的隔离环境，可以并行跑多种配置，用同一套检查评估。
  • Stablehand：★13。自托管的无人值守 agent：用 YAML 定义，跑在容器里，高风险动作要人批准，有预算上限，每次运行留回执。

身份权限与 MCP 网关

  • AI Agent Gateway（Tuskira，★83）：每次 tools/call 都按 agent 档案校验，不只是在工具列表里过滤；key 绑定档案后，调用方不能自报身份。凭据从加密库按请求注入，可轮换；Skills 挂在档案上，通过 MCP 下发。要读的文档：docs/profiles.md、docs/connectors-and-credentials.md、docs/security-model.md。
  • skgate（★13）、heldkeys（★6）、erebus（★6）：分别做 MCP 的 OAuth、凭据盘点和签名回执，细节见第三节。

评测与可观测

  • agent-eval：★22。改动前后重放评测集，用统计检验（McNemar 加 bootstrap）判断是真变差还是噪声，在 CI 里给出合并或阻断，可直接当 CI 门禁的参考。
  • PACE-Bench：★22。在企业老仓库里按 PRD 逐项评测完成度；没有 License，只能参考方法。
  • AOS Dashboard / AOS-1：★90。只读监控，配一份开放规范：心跳、纯文件状态、事件日志。

成本与模型路由

  • Antirion：★293。Rust 写的网关：组织、团队、项目、key 四级预算，支持 SSO/SAML/SCIM，有审计。
  • Stigg Agent SDK：★7。调用前查权益和额度，调用后计量；后端是商业服务。
  • 其他：DeepSeek 官方推理框架 DeepInfer（★22,399）属推理侧，不入库。OpenAI Decisions API 正式可用，做分类和判定，不生成完整回复。Codex 对话中途改推理档位不再让缓存失效。

代码审查与 CI

  • lessloc：★102。一套「少写代码」护栏，适配 10 家 hook；「代码少 36%」是作者自报。
  • Diffinery：★13，10-26 刚发布。跑在自己 Cloudflare 账号上、以 agent 为先的 GitHub + Actions 替代。

三、空白方向有无进展

  • MCP 网关 / 工具鉴权：有，而且是本周最大进展。
    • Tuskira：按档案强制授权，凭据由网关注入。
    • skgate：MCP 的 OAuth 2.1 实现（internal/mcp/oauth.go），外加 OIDC 管理员登录、虚拟 key。
    • heldkeys：启动 agent 前盘点它在本机、沙箱或 CI 里能拿到哪些凭据。
    • 闭源参考：Alter（YC 的商业 agent 特权访问管理）、Vercel 的计划即权限（博客）。
  • SSO/RBAC：有。 Antirion 内置 OIDC、SAML 登录、SCIM 账号同步和权限控制。Tuskira 有多租户隔离。
  • 合规审计：有。
    • erebus：每次执行签发可离线验证的签名回执，cosign 就能验；README 明确说它不证明模型算对了。
    • OpenShell 的审计日志改为 OCSF 标准格式。
  • 计费：有。 Antirion 做多级预算和成本账本；Stigg SDK 给出「调用前查权益、调用后计量」的接口形态。开源的团队分摊（chargeback）方案仍然没有。
  • 按权限过滤的检索（ACL-aware RAG）：仍然空白。 基线还是 Onyx；OpenViking v0.5.2 的隐私提取最接近。
